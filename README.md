# OrderMemo

WooCommerceの注文編集画面の「注文メモ」欄に、あらかじめ登録した定型文をワンクリックで挿入できるようにするプラグインです。発送連絡・入金確認・キャンセル案内など、毎回同じ文面を手で打つ作業をなくします。

テンプレートには差し込みタグ（`{customer_name}` など）が使え、挿入した瞬間にその注文のデータへ展開されるため、送信前に完成した文面を目で確認・手直しできます。

## 必要環境

- WordPress 6.7 以上
- PHP 8.3 以上
- WooCommerce（HPOS/従来型どちらの注文ストレージにも対応）

## 使い方

1. 管理画面の **WooCommerce > 注文メモテンプレート** でテンプレートを登録します（タイトルと本文のみ。「順序」で表示順を調整できます）。
2. 注文編集画面を開くと、「メモを追加」欄の上にテンプレート選択と「挿入」ボタンが表示されます。
3. テンプレートを選んで「挿入」をクリックすると、差し込みタグが展開された文面がテキストエリアの末尾に追記されます（入力中の文章は消しません）。
4. 文面を確認・編集し、メモの種類（非公開メモ／顧客へのメモ）を選んで「追加」をクリックするのは通常通りの操作です。

## 差し込みタグ

| タグ | 展開内容 |
| --- | --- |
| `{customer_name}` | 請求先の氏名 |
| `{order_number}` | 注文番号 |
| `{order_date}` | 注文日 |
| `{order_total}` | 合計金額（通貨記号付き） |
| `{payment_method}` | 支払方法 |
| `{shipping_method}` | 配送方法 |
| `{site_name}` | サイト名 |

### 開発者向け：独自タグの追加

`ormm_tags` フィルターで差し込みタグを追加・上書きできます。

```php
add_filter( 'ormm_tags', function ( $tags, $order ) {
	$tags['{tracking_number}'] = (string) $order->get_meta( '_tracking_number' );
	return $tags;
}, 10, 2 );
```

## 仕様上の注意

- テンプレート本文はプレーンテキストとして保存されます（HTMLタグは保存時に除去されます）。
- 「顧客へのメモ」はWooCommerceの仕様によりそのままメール送信されます。挿入後に文面を確認してから「追加」をクリックしてください。
- テンプレートが1件も登録されていない注文編集画面では、挿入UIは表示されません。
