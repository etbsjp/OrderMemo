WooCommerce の注文編集画面で、定型文をワンクリックで注文メモに挿入できるプラグインです。

== Description ==

WooCommerce の注文編集画面にテンプレート挿入機能を追加します。あらかじめ登録した定型文を、ワンクリックで注文メモに入力できます。定型文には差し込みタグを使えます。

= 動作環境 =

* WooCommerce
* PHP 7.4 以上

WordPress のバージョン下限は設けていません。
